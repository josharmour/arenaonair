# ArenaOnAir

Play-by-play radio-style narration for MTG Arena matches. Watches the MTGA Player.log,
reconstructs the public game state from GRE events, and narrates what happens — like a
broadcast announcer. Follows the story of the game (momentum, resources, arcs), not just
the turn-by-turn plays. **Never tells you what to play.**

Cross-platform from day one: Windows, macOS, and Linux with an identical feature set.

- `docs/PRD.md` — product requirements
- `docs/DESIGN.md` — design document and build plan

Status: design phase. Implementation not started.
