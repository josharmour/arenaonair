Engineered for Competitive Play

ArenaOnAir is built from the ground up for zero distraction, accurate game understanding, and zero latency.

Zero-Lag Polling

Directly reads Unity log streams at 200Hz without artificial queue blocks. The moment an action resolves in MTGA, the diff engine processes it instantly.

Dynamic Tempo Adaptation

Playing fast? ArenaOnAir detects high tempo, drops un-spoken backlogs, switches to punchy short-form phrases, and silences low-salience routine filler.

QR6 Anti-Drone Engine

Guaranteed structural variety. The anti-drone corpus rotates sentence shapes, actor leads, card leads, and layman glosses with a rolling 8-utterance memory window.

100% Local & Safe

Runs purely off Wizards' official player diagnostic logs. Zero game memory hooks, zero network tampering, and zero cloud accounts required.

20,000+ Card Database

Local SQLite cache resolves MTGA grpIds into full card names, layman glosses, mana costs, and card categories with instantaneous zero-latency lookups.

Cross-Platform TTS

Supports Kokoro neural voice out-of-the-box, with built-in zero-dependency fallbacks to macOS say, Windows SAPI, and Linux Piper/eSpeak.

Quickstart Installation

Install ArenaOnAir locally on macOS, Windows, or Linux in under two minutes.

# 1. Clone & install ArenaOnAir
git clone https://github.com/josharmour/arenaonair.git
cd arenaonair

# 2. Install dependencies with Kokoro neural voice
pip install -e ".[dev]" kokoro soundfile

# 3. Start the live commentator daemon
python -m arenaonair.app
Make sure Detailed Logs (Plugin Support) is enabled in MTG Arena Settings > Account. Full setup documentation →
